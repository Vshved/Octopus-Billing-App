# ClubBilling - Касова система для клубу

Модульна структура проекту для зручного редагування та підтримки.

## 📁 Структура проекту

```
club_billing/
├── main.py                 # Точка входу в програму
├── constants.py            # Константи (шляхи, дні тижня, мітки)
├── models.py              # Моделі даних (Batch, Session)
├── billing.py             # Логіка розрахунків
├── tariffs.py             # Управління тарифами
├── storage.py             # Збереження/завантаження даних
├── utils.py               # Допоміжні функції
├── styles.py              # Стилі інтерфейсу
├── dialogs.py             # Діалогові вікна
└── main_window.py         # Головне вікно (розділено на 3 частини)
```

## 🚀 Запуск

```bash
python main.py
```

## 📦 Модулі

### constants.py
Містить всі константи проекту:
- Шляхи до файлів (`TARIFFS_PATH`, `BILLS_CSV`, `SESSIONS_PATH`)
- Українські назви днів тижня
- Мітки годин для тарифів

### models.py
Класи даних:
- `Batch` — пакет людей, що прийшли в один час
- `Session` — сесія (стіл) з методами розрахунку

### billing.py
Логіка розрахунків:
- `ceil_to_step()` — округлення хвилин
- `hourly_sum()` — розрахунок суми за погодинними тарифами

### tariffs.py
Робота з тарифами:
- `default_tariffs()` — тарифи за замовчуванням
- `load_tariffs()` — завантаження з JSON
- `save_tariffs()` — збереження в JSON

### storage.py
Робота з файлами:
- `save_active_sessions()` — збереження активних столів
- `load_active_sessions()` — завантаження активних столів
- `save_closed_session()` — збереження закритих сесій в CSV

### utils.py
Допоміжні функції:
- `create_choice_button()` — створення кнопки-селектора замість ComboBox

### styles.py
Стилі інтерфейсу:
- `apply_global_style()` — застосування глобальних CSS-стилів

### dialogs.py
Діалогові вікна:
- `EditSessionDialog` — редагування сесії
- `PartialBillDialog` — частковий розрахунок

### main_window.py
Головне вікно програми (розділено на 3 файли для зручності):
1. **Частина 1** — ініціалізація, меню, центральна частина
2. **Частина 2** — методи роботи зі столами
3. **Частина 3** — оновлення таблиці, діалоги налаштувань

## 🔧 Як редагувати

### Зміна тарифів за замовчуванням
Відредагуйте функцію `default_tariffs()` у файлі `tariffs.py`

### Додавання нової функції
1. Додайте метод у відповідний модуль
2. Імпортуйте його в `main_window.py` або інший модуль

### Зміна стилів
Відредагуйте функцію `apply_global_style()` у файлі `styles.py`

### Додавання нового діалогу
Створіть клас у `dialogs.py` та імпортуйте його в `main_window.py`

## 📝 Примітки

- Всі файли використовують UTF-8 кодування
- Для роботи потрібен PyQt6
- Автозбереження активних сесій при закритті програми
- Підтримка клавіатурних скорочень (Ctrl+N, Ctrl+E, Ctrl+P, Ctrl+T, Delete)
